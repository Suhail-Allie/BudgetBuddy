# Bomb Squad – Client Management & Project Tracking System

Task 1 prototype for XISD5319. This repository contains the responsive website and Android mobile application prototype described in the project plan.

## Structure
- `Website/` – HTML, CSS and JavaScript responsive web interface.
- `MobileApp/` – Android Studio Kotlin application prototype.

## Website
Open `Website/index.html` in a browser, or use VS Code Live Server.

## Mobile App
Open the `MobileApp` folder in Android Studio and run on an emulator/device.

## Main functions represented
Login/registration, dashboard, project requests/tracking, milestones, documents, invoices/payment status, notifications, reports, profile/settings and role-based navigation placeholders.
